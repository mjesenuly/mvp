# Reviewed design references

No Lovable, v0 or Claude Design execution is claimed. The orchestrator retrieved the following primary references on 20 October 2026 and supplied their concrete patterns to the engineer.

- [GOV.UK tables](https://design-system.service.gov.uk/components/table/): semantic captions, scoped column headings and right-aligned amounts inform the offer comparison table.
- [GOV.UK error summary](https://design-system.service.gov.uk/components/error-summary/): clear error recovery informs visible form error notices; the MVP does not claim every GOV.UK accessibility behavior.
- [USWDS process list](https://designsystem.digital.gov/components/process-list/): sequential steps inform the repair lifecycle indicator.
- [GOV.UK file upload](https://design-system.service.gov.uk/components/file-upload/): explicit input labels and file restrictions inform photo submission.
- [Stripe Invoicing](https://stripe.com/invoicing): separated line items and total hierarchy inform required fees, known subtotal and optional charges. No payment integration is included.

These are interaction and layout references, not copied branding or assets. Light neutral surfaces, restrained blue accents and English copy come from product discovery. Unknown fees remain explicit; accepted terms and revision history remain visible to authorized parties.
