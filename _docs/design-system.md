# Design system

English, light neutral backgrounds, restrained blue action accents, readable system sans typography and generous spacing. Use semantic headings/forms, visible focus, keyboard access, labels/errors and responsive layout. Never encode status by color alone.

Primary layout centers on request detail: device/fault/photos, lifecycle timeline and comparison table. Comparison rows distinguish known subtotal, optional charges, unknown fees, turnaround, warranty and scope. Do not label cheapest as best. Small-screen offer details stack with equivalent labels. Pending revision prominently blocks work and exposes customer accept/reject actions. Role-specific actions remain explicit; server enforces permissions. Avoid interchangeable-card-only dashboard and external demo images.
