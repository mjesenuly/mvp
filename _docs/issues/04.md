## Acceptance criteria

- [ ] TypeORM EntitySchema models and versioned migrations create real SQLite storage through sqljs autosave; synchronize disabled.
- [ ] Repository adapter preserves existing API/domain interface and shared behavior tests pass on memory and SQLite.
